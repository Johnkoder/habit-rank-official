# HabitRank

HabitRank is a gamified, offline-first Android habit tracker that turns everyday habits into progression through XP, streaks, ranks, achievements, and seasons.

> **Development approach:** HabitRank is an AI-assisted / vibe-coded personal project. I drive the product idea, feature decisions, UI direction, testing, iteration, and releases while using AI coding tools heavily during implementation.

## ✨ Features

- ✅ Create habits with difficulty levels and weekday schedules
- 🔥 Build streaks by completing scheduled habits consistently
- ⭐ Earn XP from completed habits
- 🏆 Progress through 10 ranks, from **Trail Scout** to **Conqueror**
- 🎖️ Unlock achievements for ranks, streaks, and total completions
- 📅 Seasonal progression built around 60-day seasons
- ↩️ Undo completions and manage recent habit history
- 🔔 Local habit reminders
- 💾 Offline-first storage — core habit data stays on the device
- 🎨 Gamified UI with character feedback and lightweight animations

## 🏆 Progression

HabitRank gives completed habits XP based on difficulty:

| Difficulty | XP |
| --- | ---: |
| Easy | 10 XP |
| Medium | 20 XP |
| Hard | 30 XP |

XP contributes to rank progression during each season. The app also tracks streak and completion milestones for achievements.

## 🔒 Privacy & Data

HabitRank is designed as a local-first app. Core habit, completion, progression, and settings data are stored locally on the device rather than requiring an account or hosted backend.
